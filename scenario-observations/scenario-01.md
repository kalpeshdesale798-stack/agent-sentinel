## 1. Purpose

Scenario 1 tests Agent Sentinel under an interruption condition.

Unlike Scenario 0, the agent must respond to an event that affects the normal flow of the task.

The scenario is designed to examine:

- Interruption handling
- Context preservation
- Reassessment
- Prioritization
- Goal continuity
- Recovery behavior

---

## 2. Scenario Description

Scenario 1, titled **"The Interrupted Service,"** introduces an interruption to the normal task environment.

The generated episode is titled:

**"The Inquiry into Portal Disruption"**

The scenario provides an opportunity to examine how Sentinel responds when an ongoing service or process is disrupted and additional information becomes relevant.
